# Bash port

Working ports of the zsh modules. About/Settings is simplified; bar, search, explorer, and jumps match the zsh UX. Needs bash 4+.

| File | |
|------|-|
| `dnav` | folder bar |
| `dfile` | file explorer |
| `djump` | jumps and `dKEY` commands |
| `dsearch` | search |
| `jumps` | default jump table |

```bash
source bash/dnav
dnav
```
